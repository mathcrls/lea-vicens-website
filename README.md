# Prototype site Léa Vicens

Prototype local préparé pour présentation à Léa.

- Design et interactions basés sur le modèle fourni.
- FR / ES / EN
- Agenda filtrable et recherche
- Galerie avec lightbox
- Modales chevaux / actualités
- Menu mobile
- Compteurs animés
- Section « Palmarès & statistiques » basée sur la temporada 2019.

## Statistiques intégrées

40 corridas, 69 oreilles, 2 rabos en 2019 et trois années consécutives en tête de l'Escalafón (2017–2019).

Les visuels actuellement présents sont ceux fournis pour ce prototype. Certains visuels sont réutilisés dans plusieurs rubriques en attendant les photos définitives de chaque cheval, actualité et membre de l'équipe.

## Utilisation

Ouvrir `index.html` dans un navigateur moderne, ou publier le dossier sur GitHub Pages pour une présentation en ligne.
